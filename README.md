# Employee Management System

## 📌 Project Description

The Employee Management System is a web-based application developed to simplify and manage employee information efficiently. It provides a user-friendly dashboard where administrators can add, view, update, and delete employee records.

The system helps organize employee details such as employee ID, name, email, phone number, department, designation, salary, joining date, and employment status.

This project is developed using React.js for the frontend, Node.js and Express.js for the backend, and MySQL for database management.

## ✨ Features

- Add new employee details
- View all employee records
- Update existing employee information
- Delete employee records
- Manage employee status (Active/Inactive)
- Responsive and user-friendly dashboard
- MySQL database integration
- REST API for backend operations

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Node.js
- Express.js
- MySQL

## 🎯 Objective

The main objective of this project is to develop an efficient employee management application that reduces manual record management and makes employee information easier to maintain.
